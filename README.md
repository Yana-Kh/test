# Тесты для OrderService.CalculateTotalAsync

## Как запустить
1. Клонирование репозитория
git clone https://github.com/Yana-Kh/test.git

2. Восстановлениеп зависимостей:
dotnet restore 

3. Добавить в папку MyProject файл, на основе которого будет проходить проверка

4. Запуск тестов в корне решения
dotnet test
